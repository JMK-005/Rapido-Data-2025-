# Rapido-Data-2025-
🛺 Rapido Ride Booking & Revenue Analysis Dashboard

[Power BI] [Python] [Excel] [Status]

📊 Project Overview

This project is an interactive Rapido Ride Booking & Revenue Analysis
Dashboard created using Microsoft Power BI. The dashboard transforms
ride-booking data into clear business insights related to bookings,
revenue, cancellations, ride distance, customer/driver ratings,
locations, and monthly performance.

The goal is to provide a simple and visual way to understand ride
demand, booking performance, revenue contribution, cancellation
patterns, and operational metrics.

🎯 Project Objectives

-   Analyze overall Rapido booking performance.
-   Track completed, cancelled, and incomplete rides.
-   Measure total booking revenue.
-   Understand ride-distance patterns.
-   Compare revenue across vehicle types.
-   Analyze pickup and drop locations.
-   Monitor customer and driver ratings.
-   Study booking and revenue trends over time.
-   Build an interactive dashboard for quick decision-making.

  Vehicle Type     Approx. Booking Value

The analysis shows that Bike rides contribute the larger share of the

🚦 Booking Status Analysis

The dataset contains three major booking outcomes:

-   Completed – Successfully completed rides.
-   Cancelled – Bookings cancelled by the customer or driver.
-   Incomplete – Rides that could not be completed, along with reasons
    such as driver delays or other operational issues.

From 30,000 records:

-   24,641 rides were completed.
-   3,559 rides were cancelled.
-   1,800 rides were incomplete.

This helps identify where ride operations can be improved.

📍 Location Analysis

The dashboard includes interactive filters for:

-   Pickup Location
-   Drop Location

This makes it possible to compare ride activity between cities and
identify frequently used routes or locations.

⭐ Rating Analysis

🧮 Example DAX Measures

Total Revenue

    Total Revenue =
    SUM('rapido'[Booking_Value])

Completed Bookings

    Completed Bookings =
    CALCULATE(
        COUNTROWS('rapido'),
        'rapido'[Booking_Status] = "Completed"
    )

Cancelled Bookings

    Cancelled Bookings =
    CALCULATE(
        COUNTROWS('rapido'),
        'rapido'[Booking_Status] = "Cancelled"
    )

Incomplete Rides

    Incomplete Rides =
    CALCULATE(
        COUNTROWS('rapido'),
        'rapido'[Booking_Status] = "Incomplete"
    )

Average Distance

    Average Distance =
    AVERAGE('rapido'[Ride_Distance(km)])

Total Distance

    Total Distance =
    SUM('rapido'[Ride_Distance(km)])
